Technical SEO skills, and the proof for each one

"Technical SEO" on a profile can mean anything from installing a plugin to rebuilding a rendering pipeline. So here's my list, specific enough to check. Every skill below is something I've done on a real site, and wherever I can show it, it links to the case study or guide that proves it. My full career history lives in my CV on chrisabraham.com; this page is the technical inventory.

Crawling and auditing whole sites

  • Full site crawls in Screaming Frog with JavaScript rendering, run in raw and rendered modes and compared, so I can see which content exists only after scripts run.
  • Custom extraction with XPath and regex to audit every URL for heading counts, canonicals, robots tags, schema types, and tracking IDs. My extraction recipes are published.
  • Near duplicate detection and multiple H1 audits across entire sites, with a decision per cluster. See how I find both.
  • Before and after crawl comparisons to prove a fix landed on every URL, described in proving an SEO fix worked.
  • Crawl and index management for a programmatic site of more than 20,000 pages: segmented sitemaps, robots rules for parameter URLs, and baselines per segment. Programmatic price index.

JavaScript rendering forensics

  • Traced a Magento and Hyvä store's traffic loss to Alpine.js sections that loaded specs, FAQs, and reviews only on scroll, and proved it with crawler extraction counts. Hidden product content.
  • Found 2,000 event pages Google never discovered in a Create React App build, and wrote the 13 page developer spec, ranked P0 to P3, that fixed it. React event app.
  • Diagnosed a consent platform that blocked the script displaying every article, so bots saw empty pages. Consent banner case.
  • Hunted hydration errors sitewide by loading every URL in scripted headless Chrome and collecting console errors by template.

Working in the code

  • Made metadata changes in a client's Sanity and Vercel codebase through a GitHub pull request the developer reviewed and merged, then verified prerendering. Headless local business.
  • Read whole repositories with Claude Code and Codex to trace a crawl finding to the component or import script that causes it, checking every answer against the live site.
  • Built SEO checks into the build of sites I run, so a page with a bad title, a duplicate description, a broken internal link, or borrowed phrasing fails before it publishes. That's how this site is built.
  • Automated IndexNow submissions with GitHub Actions, gated on the new sitemap actually being live.
  • Built a 12,000 line command line assistant in Python with 140 end to end tests, directing Claude Code the way a technical lead directs a team.

Migrations, redirects, and recovery

  • Audited a Squarespace to Shopify move that left 3,400 broken URLs and duplicate product paths, and did the theme schema work. Shopify cleanup.
  • Rebuilt the redirect map for a site that had lived on three platforms over fourteen years, by pulling every URL the Wayback Machine ever captured, testing all 848 against the live site, and redirecting every one that had ever served a page.
  • Diagnosed a WooCommerce store's loss of indexing, traffic, and AI referrals after its SEO plugin was switched off, and checked the recovery. Plugin outage.

Schema, entities, and AI search

  • Separated a multi state brand from its first showroom in schema and on the page, so search engines stopped blurring the two. Closet locations.
  • Fixed a gym whose brand name Google read as an ordinary word, which lifted calls and visits. Training gym.
  • Audited how ChatGPT and Perplexity described an AI company's jobs and pay, and planned the fix. Recruiting answers.
  • Built JSON-LD graphs, llms.txt files, Markdown twins of every page, and full text feeds for AI crawlers, on this site and others I run.

  • Moved domains to Cloudflare DNS without breaking Google Workspace mail, and set up SPF, DKIM, and DMARC. See protecting a domain that sends no mail.
