Technical SEO skills, and the proof for each one

"Technical SEO" on a profile can mean anything from installing a plugin to rebuilding a rendering pipeline. So here's my list, specific enough to check. Every skill below is something I've done on a real site, and wherever I can show it, it links to the case study or guide that proves it. My full career history lives in my CV on chrisabraham.com; this page is the technical inventory.

Crawling and auditing whole sites

  • Full site crawls in Screaming Frog with JavaScript rendering, run in raw and rendered modes and compared, so I can see which content exists only after scripts run.
  • Custom extraction with XPath and regex to audit every URL for heading counts, canonicals, robots tags, schema types, and tracking IDs. My extraction recipes are published.
  • Near-duplicate detection and multiple H1 audits across entire sites, with a decision per cluster. See how I find both.
  • Before-and-after crawl comparisons to prove a fix landed on every URL, described in proving an SEO fix worked.
  • Crawl and index management for a programmatic site of more than 20,000 pages: segmented sitemaps, robots rules for parameter URLs, and baselines per segment. Programmatic price index.

JavaScript rendering forensics

  • Traced a Magento and Hyvä store's traffic loss to Alpine.js sections that loaded specs, FAQs, and reviews only on scroll, and proved it with crawler extraction counts. Hidden product content.
  • Found 2,000 event pages Google never discovered in a Create React App build, and wrote the 13 page developer spec, ranked P0 to P3, that fixed it. React event app.
  • Diagnosed a consent platform that blocked the script displaying every article, so bots saw empty pages. Consent banner case.
  • Hunted hydration errors sitewide by loading every URL in scripted headless Chrome and collecting console errors by template.

Working in the code

  • Hacked Perl and PHP by the bucketful long before AI coding assistants: Movable Type's Perl CGI scripts, PHP-Nuke and PostNuke portals, and scripts of my own. Reading somebody else's codebase has felt like home ever since.
  • Made metadata changes in a client's Sanity and Vercel codebase through a GitHub pull request the developer reviewed and merged, then verified prerendering. Headless local business.
  • Read whole repositories with OpenAI Codex and Claude Code to trace a crawl finding to the component or import script that causes it, checking every answer against the live site.
  • Built SEO checks into the build of sites I run, so a page with a bad title, a duplicate description, a broken internal link, or borrowed phrasing fails before it publishes. That's how this site is built.
  • Automated IndexNow submissions with GitHub Actions, gated on the new sitemap actually being live.
  • Built a 12,000 line command line assistant in Python with 140 end-to-end tests, directing Claude Code the way a technical lead directs a team.

Migrations, redirects, and recovery

  • Audited a Squarespace to Shopify move that left 3,400 broken URLs and duplicate product paths, and did the theme schema work. Shopify cleanup.
  • Rebuilt the redirect map for a site that had lived on three platforms over fourteen years, by pulling every URL the Wayback Machine ever captured, testing all 848 against the live site, and redirecting every one that had ever served a page.
  • Diagnosed a WooCommerce store's loss of indexing, traffic, and AI referrals after its SEO plugin was switched off, and checked the recovery. Plugin outage.

Schema, entities, and AI search

  • Separated a multi-state brand from its first showroom in schema and on the page, so search engines stopped blurring the two. Closet locations.
  • Fixed a gym whose brand name Google read as an ordinary word, which lifted calls and visits. Training gym.
  • Audited how ChatGPT and Perplexity described an AI company's jobs and pay, and planned the fix. Recruiting answers.
  • Built JSON-LD graphs, llms.txt files, Markdown twins of every page, and full-text feeds for AI crawlers, on this site and others I run.

Servers, DNS, and email

  • Got my first root access on a Sun SPARCstation running Solaris, the pizza box kind, as the image lab administrator at PNI, Picture Network International.
  • Ran Linux servers and built on Apache, MySQL, Perl, and PHP for years before anyone called that combination the LAMP stack, right up until my SEO career began in 2002.
  • Revived a stalled Node application on a DigitalOcean server over SSH: read the logs, fixed the configuration, managed it with PM2, and found the port conflict keeping it down.
  • Administer my own Debian servers with key only SSH, firewalls, and unattended security updates.
  • Moved domains to Cloudflare DNS without breaking Google Workspace mail, and set up SPF, DKIM, and DMARC. See protecting a domain that sends no mail.

Email and Google Workspace

  • Run Google Workspace administration end to end: users, aliases, groups, Gmail routing, Calendar, and Drive sharing.
  • Know mail from the server up: Sendmail on Linux, IMAP and POP3, SMTP ports, and the DNS records that tell the world where your mail lives and who may send it.
  • Diagnose mail that bounces or lands in spam, and lock down domains that never send mail so nobody can borrow their names, as in protecting a domain that sends no mail.

Local search and Google Business Profile

  • Got a suspended profile reinstated with a documented appeal. Profile reinstated.
  • Rescue profiles stuck in failed verification: reconcile the listing with the real business and its paperwork, then script the owner's one-take video so it shows every proof Google asks for. My video verification checklist is published.
  • Build appeals like a legal brief: the most authoritative document first, nothing that exposes private data, and no date claimed that the paperwork doesn't support.

Data

  • Wrote Python pipelines that built an 88,900 contact master list, merged two 28,800 record exports at 94% email coverage, and caught an AI-built tracker inventing its data.

Strengths that don't fit on a skills list

These are habits, not tools, and they shape every engagement.

  • I keep two problems apart. When a traffic loss and a spam spike land in the same month, I run them as separate investigations until the evidence connects them, so nobody spends a quarter fixing the wrong thing. It's built into every technical SEO audit.
  • I catch AI tools inventing things. I use AI every day and trust none of it unchecked, which is how I caught an AI-built outreach tracker logging messages to contacts who didn't exist. My guide to correcting what AI says about you comes from the same habit.
  • I build a case like a brief. I captained my high school speech and debate team, and my Google appeals still read that way: the strongest document first, nothing that exposes private information, and no date claimed without paper behind it. That's how a suspended profile came back.
  • I vet sources for a living. At Edelman my job included checking online influencers for a genuine, multi-year track record before clients went near them. I bring the same suspicion to every crawl export, vendor dashboard, and confident AI answer.
  • I write for the developer and the owner at once. The same finding becomes a ranked ticket with acceptance criteria for engineering and a plain summary for the person paying, as in the 13-page spec for a React app.
  • I ship at speed without dropping the checks. This site went from first commit to 75 pages and more than 50,000 words in a week, built with Claude Code under my direction, and every page passes automated checks for title and description length, duplicate wording, broken links, and voice before it publishes.
  • I've made myself machine readable. Two decades of publishing under one name, tied together with structured data so search engines and AI tools know the profiles belong to one person. The method is in two names, one entity.
  • I know how online communities behave from the inside. I moderate a Reddit community of more than 16,000 runners and have for nine years, and Reddit threads turn up constantly in AI answers. The story is off the clock.
